# 资源猫电脑版

适用于 Windows 10 / 11 x64 的独立桌面程序，支持内置播放器、PotPlayer、播放进度、在线和离线缓存。

## 下载安装

在 [最新版本](https://github.com/shredier/resourcecat-desktop-releases/releases/latest) 下载 Setup.exe，或下载分享 ZIP 后解压安装。

升级前请完全退出资源猫（包括系统托盘），覆盖安装到原目录，无需卸载；收藏、记录、设置和缓存会保留。

从 0.9.10 起，可在“设置 → 关于 → 检查更新”查看新版。默认启动后每 12 小时检查一次，可关闭；下载安装由用户主动进行。旧版需要先手动安装 0.9.10 一次。

安装包包含运行时，无需另装 Node.js。缺少 Microsoft Edge WebView2 时会引导安装。本项目暂未购买 Windows 代码签名证书。

此仓库仅保存公开安装包和更新清单，不公开应用源码、个人资料或 API Key。安卓版位于 [独立仓库](https://github.com/shredier/resourcecat-android-releases)。
